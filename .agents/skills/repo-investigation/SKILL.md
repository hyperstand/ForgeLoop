## Purpose
Understand the task area without edits.
## Procedure
1. `list_files` the worktree; 2. `read_file` entry points + AGENTS.md; 3. `search` for symbols.
4. Record relevant files and risks; stop and ask if evidence is insufficient.
## Validation
Cite every file touched by the later plan. No edits in this skill.
